🎯 SGIO - Sistema de Gestión Integral de Obras
------------------------------------------------------------------------
🏗️ Descripción

- El Sistema de Gestión Integral de Obras (SGIO) es una aplicación web diseñada para optimizar la gestión de proyectos de construcción. Con SGIO, la empresa puede administrar de manera eficiente usuarios, roles, empleados, proyectos, fases, tareas, hitos, inventario y proveedores garantizando un control detallado y una mejora en la productividad.
------------------------------------------------------------------------
🚀 Características Principales
- 👤 Gestión de Usuarios y Roles
- ✔️ Creación, edición y eliminación de usuarios.
- ✔️ Asignación y actualización de roles.
- ✔️ Activación y bloqueo de usuarios.
- ✔️ Autenticación segura basada en cookies.

🏗️ Gestión de Proyectos
- ✔️ Creación, edición y eliminación de proyectos.
- ✔️ Asignación de clientes a proyectos.
- ✔️ Visualización del progreso con barra de avance dinámica.

📋 Fases y Tareas
- ✔️ Creación y administración de fases dentro de cada proyecto.
- ✔️ Gestión completa de tareas: agregar, editar y eliminar.
- ✔️ Marcar tareas como completadas con AJAX.
- ✔️ Modal de confirmación mejorado para cambios.
- ✔️ Gráficos circulares para visualizar el estado de las tareas:
- 🔴 Rojo: No completadas | 🟢 Verde: Completadas

📊 Dashboard Interactivo
- ✔️ Gráficos dinámicos con Chart.js para visualizar hitos, tareas y fases.
- ✔️ Colores representativos: 🟢 Completadas | 🔴 Pendientes.
- ✔️ Barras de progreso animadas para un mejor seguimiento.

------------------------------------------------------------------------

🛠️ Tecnologías Utilizadas
- 🔹 ASP.NET Core MVC – Framework robusto para aplicaciones web.
- 🔹 Entity Framework Core – ORM eficiente para gestión de datos.
- 🔹 SQL Server – Base de datos relacional de alto rendimiento.
- 🔹 Bootstrap 5 – Diseño responsivo y moderno.
- 🔹 DataTables – Gestión avanzada e interactiva de tablas.
- 🔹 Chart.js – Visualización de datos con gráficos dinámicos.
- 🔹 JavaScript (AJAX & jQuery) – Interactividad y mejor experiencia de usuario.
